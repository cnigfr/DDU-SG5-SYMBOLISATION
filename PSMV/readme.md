# Ressources pour les PSMV

- _[Le catalogue des symbolisations PSMV](/PSMV/Catalogue_Symbolisation_CNIG_PSMV.pdf)_ est un récapitulatif illustré des préconisations de symbologie au format PDF. Pour chaque type de zone, sous-code de prescription ou sous-code d'information, il indique les spécifications des symboles recommandés sous une forme littérale pouvant être déclinée pour d'autres contextes.
- [La Planche de symbolisation](/PSMV/Planche_Symbolisation_CNIG_PSMV.pdf) est une synthèse des symbolisations sous forme d'une affiche PDF au format A1 imprimable.
- le répertoire [ArcGISpro](/PSMV/ArcGISpro) contient le fichier STYLX qui met en oeuvre les spécifications. Il peut être directement appliqué sur les tables des prescriptions, informations et zones des PSMV au standard CNIG. Ce fichier a été créé avec ArcGIS pro 2.9 et est compatible avec les versions supérieures.
- le répertoire [QML](/PSMV/QML) contient les fichiers QML qui mettent en oeuvre les spécifications. Ils peuvent être directement appliqués sur les tables des prescriptions, informations et zones des PSMV au standard CNIG. Ces fichiers ont été créés avec QGIS 3.10 et sont compatibles avec les versions supérieures.
- le répertoire [symboles](/PSMV/symboles) contient des fichiers XML qui décrivent indépendamment les symboles associés à chaque code ou sous-code, soit la décomposition des QML en symboles unitaires

# Ressources pour les PSMV

### [*Le catalogue des symbolisations PSMV*](/PSMV/Catalogue_Symbolisation_CNIG_PSMV.pdf) 
Il s'agit d'un **récapitulatif illustré** des préconisations de symbologie au format PDF. Pour chaque type de zone, sous-code de prescription ou sous-code d'information, il indique les spécifications des symboles recommandés sous une forme littérale pouvant être déclinée pour d'autres contextes.

### [La Planche de symbolisation](/PSMV/Planche_Symbolisation_CNIG_PSMV.pdf) 
Il s'agit d'une synthèse des symbolisations sous forme d'une affiche PDF au format A1 imprimable.

### Répertoires
- [ArcGISpro](/PSMV/ArcGISpro) contient le fichier de style STYLX qui met en oeuvre les spécifications. Il peut être directement appliqué sur les tables des prescriptions, informations et zones des PSMV au standard CNIG. Ce fichier a été créé avec ArcGIS pro 3.3 et est compatible avec les versions supérieures.
- [QGIS](/PSMV/QGIS) contient le fichier de style XML qui met en oeuvre les spécifications. Ils peut être directement appliqués sur les tables des prescriptions, informations et zones des PSMV au standard CNIG. Ce fichier a été créé automatiquement avec l'outil SLYR.
- [SLD](/PSMV/SLD) contient les fichiers SLD, associés aux svg correspondants pour une utilisation sur serveur cartographiques. Ces fichiers ont été créé automatiquement avec l'outil SLYR
